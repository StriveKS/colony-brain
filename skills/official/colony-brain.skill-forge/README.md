# colony-brain.skill-forge

A colony-brain Skill for helping users create, package, review and submit new Skills.

## Purpose

This Skill turns practical workflows into reusable Skill packages.

## Use it for

- creating a new Skill from an idea;
- turning a project workflow into a reusable process;
- improving an existing Skill;
- preparing a submission for review;
- creating `SKILL.md`, README, examples, templates and scripts.

## Relationship with WorldWideBridges.MVP-allmight

`WorldWideBridges.MVP-allmight` detects opportunities during MVP work.

`colony-brain.skill-forge` packages those opportunities into publishable Skills.

```text
MVP workflow -> opportunity -> SkillForge -> Skill package -> review -> colony-brain
```
