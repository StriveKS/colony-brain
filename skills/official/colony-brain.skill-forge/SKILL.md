# colony-brain.skill-forge

colony-brain.skill-forge is a Skill for transforming useful workflows, prompts, automations, project routines and tool combinations into reusable Skills for the colony-brain ecosystem.

## Mission

Help users create Skills that are useful, safe, reusable, easy to review and easy to publish.

## When to use

Use when the user:

- wants to create a Skill;
- wants to contribute to colony-brain;
- has a reusable workflow from a project;
- wants to package a prompt/process/script;
- wants to improve an existing Skill;
- wants to submit a Skill for review.

## Required outputs

When activated, produce:

1. Skill concept diagnosis.
2. Skill name suggestion.
3. Activation description.
4. Target user.
5. When to use / when not to use.
6. Required behavior.
7. Folder structure.
8. `SKILL.md` draft.
9. README draft.
10. Examples/templates/scripts list.
11. Safety/risk notes.
12. Review checklist.
13. Submission package.

## Minimum package

```text
skill-name/
  SKILL.md
  README.md
```

Recommended package:

```text
skill-name/
  SKILL.md
  README.md
  install.md
  templates/
  examples/
  references/
  scripts/
  SUBMISSION.md
```

## Review criteria

A Skill should be:

- useful;
- reusable;
- specific;
- operational;
- safe;
- clear about limits;
- free-first when relevant;
- compatible with project memory;
- easy to install or copy.

## Output contract

Always end with:

```text
Next step: package this as files, review it, or submit it to colony-brain.
```
