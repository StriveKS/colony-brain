# WorldWideBridges.MVP-allmight

Skill aberta para criar, organizar, lancar e evoluir projetos e MVPs usando ferramentas gratuitas, conexoes simples, Google Workspace, GitHub, Apps Script, planilhas, marketing, entrega e memoria operacional portatil entre LLMs.

## Para quem serve

- Pessoas com uma ideia e pouco ou nenhum orcamento.
- Devs iniciantes que precisam de um caminho pratico.
- Makers criando MVPs rapido.
- Freelancers e pequenos times.
- Devs experientes que querem acelerar prototipos sem perder organizacao.

## O que ela faz

A Skill ajuda a:

- escolher ferramentas gratuitas ou baratas;
- conectar Google Drive, Sheets, Apps Script, GitHub e outras ferramentas;
- criar uma base de memoria do projeto;
- montar uma stack 100% gratuita;
- montar uma stack barata mais robusta;
- planejar fases de produto, design, marketing, entrega e operacao;
- orientar o uso de diferentes LLMs conforme a tarefa;
- manter historico em Markdown para nao perder contexto entre chats.

## Como usar rapido

1. Leia `SKILL.md`.
2. Copie o conteudo para a sua LLM ou instale como skill quando sua plataforma permitir.
3. Crie uma pasta `Projetos` no Google Drive.
4. Dentro dela, crie `Memoria` e `Planilhas`.
5. Use o script em `scripts/criar-base-projeto-drive.gs` para criar a base de cada projeto.
6. Atualize sempre o `PROJECT_HISTORY.md`.

## Base recomendada no Drive

```text
Projetos/
  Memoria/
    [PROJETO] - PROJECT_HISTORY.md
    [PROJETO] - CONTEXTO_LLM.md
    [PROJETO] - DECISOES.md
    [PROJETO] - PROMPTS.md

  Planilhas/
    [PROJETO] - Acompanhamento
```
